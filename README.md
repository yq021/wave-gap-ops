# 波隙作业 · Wave Gap Ops（往返任务）

一个纯前端、单文件、零依赖的浏览器小游戏（跳跳乐玩法）：在一张会不断扩散的波场里，靠「闪现」移动到任务点，作业 2 秒后原路撤回撤离圈，全程被波环碰到会掉命。

**在线玩**：https://yq021.github.io/wave-gap-ops/

## 玩法

1. 出生点在 `a` 点正南 1500 m，`a` 点是任务圈（白色）。
2. 移动只能靠「闪现」，**每条指令距离限制 0–55 m**，单程满步约 28 次，往返约 56 次。
3. 走进 `a` 点任务圈会自动停下并开始作业，作业满 2 秒即完成去程，随后原路撤回撤离圈。
4. 波场从中心向外持续扩散，**碰到波环掉一条命**（3 条命），回程时波环已铺满大半张地图，需要看着「最近波前」卡波隙撤离。
5. 通关计时包含完整往返，本机最佳成绩保存在浏览器 `localStorage`。

## 操作

| 操作 | 说明 |
| --- | --- |
| 鼠标点击 | 朝该点闪现（不超过步幅 55 m） |
| `WASD` / 方向键（按住） | 连续闪现；延迟或冷却期间的点击/按键会缓存一条预输入 |
| `空格` | 暂停 / 继续 |
| `R` | 重置本局 |
| `V` | 切换局部波痕视角（锁定跟随） |

右侧面板还可以调步幅、波速、时间缩放、是否内嵌等参数，并切换数学极角 / 罗盘方位角（切换会重开一局）。

## 技术说明

- 单个 `index.html`，HTML + CSS + Canvas 2D + 原生 JS 全内联，**无外部请求、无 CDN、无构建**。
- 适配桌面浏览器，窗口放大可看到更多波场。
- 想本地玩：直接双击 `index.html`，或 `python -m http.server` 后访问。
